# DEA-C01 Exam Overview

## Purpose

The AWS Certified Data Engineer - Associate (DEA-C01) exam validates ability to implement data pipelines and to monitor, troubleshoot, and optimize cost and performance following AWS best practices.

## Target candidate

- About 2–3 years of data engineering experience
- About 1–2 years of hands-on AWS experience
- Understanding of volume, variety, and velocity impacts on ingestion, modeling, security, and storage choices

## Format (official)

| Item | Value | Source |
| --- | --- | --- |
| Duration | 130 minutes | AWS certification page |
| Questions | 65 total | AWS certification page |
| Scored / unscored | 50 / 15 (unidentified) | Exam guide |
| Types | Multiple choice, multiple response | Exam guide |
| Passing score | 720 / 1000 (scaled) | Exam guide |
| Scoring model | Compensatory (overall pass; not per-domain) | Exam guide |

## Domains and weights

1. **Data Ingestion and Transformation** — 34%
2. **Data Store Management** — 26%
3. **Data Operations and Support** — 22%
4. **Data Security and Governance** — 18%

## Out of scope (examples)

- Performing ML training and inferences as a primary skill
- Language-specific syntax trivia
- Drawing business conclusions from data
