# Answer explanations

Each published question JSON under `content/questions/` includes a full `explanation` field used by the grader.

## How to study explanations

1. Attempt in **Drill** with delayed feedback first.
2. Read the explanation and open the linked concept in `domains/` or `aws-services/`.
3. Mark confidence; SM-2 scheduling uses that signal in Smart Review.

## Provenance

All keys are `original` for this repository. Community sources informed **topics only**, not wording.
